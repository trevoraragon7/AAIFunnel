# AGENTS.md

Use Framer Motion for all animations.

## Baseline Requirements

- Smooth purposeful entrances, not generic fade-ins.
- Staggered reveals.
- Hover interactions.
- Premium SaaS aesthetic.
- Responsive design.
- Tailwind CSS styling.

## Design Inspiration

- Linear.
- Vercel.
- Stripe.
- Apple.
- Awwwards Site of the Day quality.

## Motion Design Standard

Create animations that feel expensive, futuristic, and unforgettable.

- Every animation must have purpose.
- Prioritize smoothness and perceived performance.
- Use Framer Motion extensively.
- Use spring physics instead of linear easing whenever possible.
- Create delight without becoming distracting.
- Review every animation after implementation.
- Replace anything generic.
- Push the motion design to the highest possible level while maintaining 60fps performance.

## Hero

- Cinematic entrance sequence.
- Layered parallax movement.
- Animated gradient or particle field.
- Floating UI elements with subtle idle motion.
- Magnetic CTA buttons.

## Scroll Effects

- Staggered reveals.
- Scroll-linked transforms.
- Depth and perspective shifts.
- Sections that feel connected through motion.
- Smooth content choreography.

## Cards

- 3D tilt on hover.
- Dynamic glow effects.
- Elevation changes.
- Animated borders.
- Micro interactions on every hover state.

## Text

- Smooth headline transitions.
